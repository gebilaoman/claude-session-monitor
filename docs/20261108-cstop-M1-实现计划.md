# cstop M1 实现计划

- 日期: 2026-11-08
- 对应设计: `docs/20261108-cstop-设计文档.md` 第 8 节 M1。
- 目标: 完成 collect + config + `--dump` 文本输出。在 macOS 本机验证数据正确性。

## 1. 本机实测补充(2026-11-08)

设计文档之外的三点事实,影响实现:

1. 项目目录下除 `<uuid>/subagents/` 外,还有 `<uuid>/tool-results/` 与 `memory/` 子目录。字节统计按「整个项目目录全量 walk」实现,自然覆盖。
2. 存在仅含 `sessions-index.json` 的项目目录。此类项目主会话数为 0,属正常数据。
3. `claude` 为原生二进制,`argv[0] == claude`。`Claude.app` 助手进程靠路径含 `Claude.app` 排除,规则有效。

## 2. 文件清单

| 文件 | 职责 |
|---|---|
| `code/go.mod` | module cstop;依赖仅 gopsutil(bubbletea/lipgloss 到 M2,go-selfupdate 到 M4) |
| `code/internal/config/config.go` | 平面 TOML 子集解析(仅 `key = int/bool` 行,含 `#` 注释),默认值,Load,InitConfig。不引入 TOML 库,保住「四个依赖」的约束 |
| `code/internal/collect/processes.go` | gopsutil 枚举进程;匹配规则(argv[0] basename == claude/claude.exe;排除路径含 Claude.app 与自身 PID);`--resume <id>` 解析 |
| `code/internal/collect/sessions.go` | 扫描 projects 根:每项目全量 walk 计字节与最近 mtime;顶层 `*.jsonl` 计主会话数 |
| `code/internal/collect/activity.go` | 活跃项目最新主会话 jsonl 末 64KB 读取;末行解析(`type`、`message.role`、content 数组 `tool_use.name`、`timestamp`);摘要生成 |
| `code/internal/collect/collect.go` | Snapshot 组装;进程 cwd → 项目 slug 关联,回填 LatestActivity |
| `code/cmd/cstop/main.go` | flag(`--refresh` `--config` `--init-config` `--dump` `--version`);`--dump` 渲染;version 变量(ldflags 注入点,默认 dev) |

可测性设计: 扫描与解析函数全部接收路径/根目录参数,不直接读全局状态。生产路径由 main 装配(`~/.claude/projects`、`os.UserConfigDir()`)。

## 3. 实现顺序与验证

1. config 包 → 验证: `go test ./internal/config/`(默认值、读写、坏行容忍)
2. collect 磁盘扫描 → 验证: fixture 目录(t.TempDir)断言会话数/字节/mtime;slug 规则
3. collect 进程与活动 → 验证: 纯函数单测(cmdline 匹配、--resume 解析、jsonl 末行解析)
4. main `--dump` → 验证: `go build`;`./cstop --dump` 与 `ps`/`du` 抽查一致
5. 提交并推送

## 4. `--dump` 输出格式

```
cstop <version>

运行中会话 N 个,内存合计 X MB [⚠]
  PID    项目          内存      运行时长   最近活动
  1423   zelig         178MB     6h34m     Bash · 12:05

磁盘 NN 个项目,合计 X.XGB [⚠]
  项目                          会话    占用      最近活动
  ...-work-zelig                42      938MB     11-07 11:24

采集降级说明(如有)
```

- 超阈值数值后追加 ` ⚠`(阈值来自 config)。
- 时长格式: `<Nd> <Nh> <Nm>`(不足一天省略天)。
